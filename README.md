# voxtext-bot
VoxText is a multilingual Telegram text-to-speech bot powered by ElevenLabs. It converts short and long texts, as well as TXT, DOCX, and PDF documents, into MP3 audio in Russian, English, and Italian, with selectable voices, playback speed, usage tracking, and admin statistics.
